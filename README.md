# Sailaab

A personal music player for the Sailaab playlist, featuring custom playback controls, song thumbnails, a complete track list, and an animated ocean-inspired interface.

- Vercel: <a href="https://sailaab.vercel.app/" target="_blank" rel="noopener noreferrer">sailaab.vercel.app</a>
- GitHub Pages: <a href="https://vipi-n.github.io/sailaab/" target="_blank" rel="noopener noreferrer">vipi-n.github.io/sailaab</a>

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000/).
